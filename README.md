# 关键词高亮助手

适用于 Chrome 和 Microsoft Edge 的 Manifest V3 浏览器扩展。它会按照本地词库自动高亮网页文字，并提供完整的词库与匹配设置。

## 功能

- 自动高亮普通网页中的关键词，默认颜色为 `#ffff00`
- 支持高亮由 `frame` / `iframe` 组成的文档站和本地整合 HTML
- 每个关键词可独立设置颜色、启用或停用
- 一个始终生效的全局词库，以及按域名/通配规则隔离的网站词库
- 首次安装自动加入通用默认词库，也可在设置页随时重新添加
- 支持批量添加、搜索、编辑和删除
- JSON 完整备份/恢复；TXT 词表导入/导出
- 支持区分大小写、完整单词匹配和动态内容监控
- 可按网站暂停高亮，支持域名与 `*` 通配规则
- 数据仅保存在浏览器本地

## 安装

### Chrome

1. 打开 `chrome://extensions/`。
2. 开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录 `keyword-highlighter`。

### Edge

1. 打开 `edge://extensions/`。
2. 开启左侧的“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本目录 `keyword-highlighter`。

安装后，在浏览器工具栏固定“关键词高亮助手”。已打开的网页需要刷新一次，后续修改词库会自动生效。

## 词库隔离

- **全局词库**：应用于所有未被排除的网站。
- **网站词库**：只有当前网址命中该词库的一条适用网站规则时才会加载。
- 当前网页最终使用“全局词库 + 所有命中的网站词库”。同名关键词以网站词库的颜色为准。
- 设置页可以新建、切换、停用或删除网站词库；工具栏弹窗会列出当前网站命中的词库，快速添加时可选择保存位置。
- JSON 会完整备份全局词库、网站词库和适用规则；TXT 仅导出设置页当前选择的词库。

## 导入文件格式

插件内置的 `default-keywords.json` 包含 42 个通用关键词，按风险、警告、重点、行动、完成状态和技术变更分类配色。已有词库的用户点击“添加默认词库”时会合并词条并自动跳过重复项。

JSON 支持以下三种结构：

```json
["关键词一", "关键词二"]
```

```json
{
  "keywords": [
    { "text": "关键词", "color": "#ffff00", "enabled": true }
  ]
}
```

也可以直接导入本扩展导出的完整 JSON 备份。普通 JSON/TXT 词表会与现有词库合并并跳过重复项；完整 JSON 备份会恢复词库和设置。

TXT 每行一个关键词，也支持扩展导出的制表符格式：

```text
关键词一\t#ffff00\t1
关键词二\t#ffb3b3\t0
```

最后一列中 `1` 表示启用，`0` 表示停用。

## 限制

浏览器安全页面（例如 `chrome://`、`edge://` 和扩展商店）不允许普通扩展注入脚本，因此不能高亮。若要处理本地 `file://` 页面，需要在扩展详情页手动开启“允许访问文件网址”。
